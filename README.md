# Tip Calculator CLI

A simple Python command-line application that calculates tips, total bills, and how much each person should pay when sharing a bill.

## Features
- Accepts bill amount and tip percentage.
- Calculates the tip amount.
- Calculates the total bill.
- Splits the bill between multiple people.
- Validates the number of people sharing the bill.

## Technologies
- Python 3
- User input
- Mathematical operations
- While loops
- Conditional statements

## How to Run

```bash
python3 tip_calculator.py
```
